# Artist & Project Reference Catalog for Device Art

This directory houses individual dossiers on key historical and contemporary artists, research groups, and activist collectives.

---

## Naming & Attachment Conventions

- Each document is named using the standard kebab-snake format:
  `[first-name-part]_[descriptor-part].md`
- Any image assets, diagrams, or PDFs associated with that dossier live in a subfolder sharing the exact same name without the `.md` extension:
  `[first-name-part]_[descriptor-part]/`
