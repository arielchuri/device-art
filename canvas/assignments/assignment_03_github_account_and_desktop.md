## Assignment Overview

In Device Art, we will use Git and GitHub to version-control our Python code, document physical computing circuits, and share open-source hardware designs. 

To prepare for our studio workflows, you will set up your GitHub account and install the visual **GitHub Desktop** client on your laptop.

---

## Step-by-Step Instructions

### Step 1: Create a GitHub Account (If you don't already have one)
1. Go to **[github.com/signup](https://github.com/signup)**.
2. Sign up using your New School email (or personal email).
3. Choose a professional or recognizable username (e.g. `firstnamelastname` or your preferred handle).
4. Verify your email address to complete registration.

---

### Step 2: Download & Install GitHub Desktop
1. Go to **[desktop.github.com](https://desktop.github.com)**.
2. Download the installer for your operating system (**macOS** or **Windows**).
3. Install and launch **GitHub Desktop**.
4. Sign in to your GitHub.com account under **Settings / Preferences $\to$ Accounts**.
5. Configure your Git identity with your Name and Email.

---

### Step 3: Clone the Course Repository Locally (Practice)
Using GitHub Desktop:
1. Go to **File $\to$ Clone Repository...** $\to$ select the **URL** tab.
2. Enter the repository URL: `https://github.com/arielchuri/device-art`
3. Choose a local folder on your computer (e.g. `Documents/device-art` or `~/device-art`).
4. Click **Clone**. You now have the full course repository, code examples, and cheatsheets on your laptop!
