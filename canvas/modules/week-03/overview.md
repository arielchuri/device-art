# Week 03: Microcontroller Programming & Circuitry (RP2040 & CircuitPython)

## Objectives
- Understand microcontroller architecture: RP2040 chip, GPIO pins, and digital input/output.
- Flash and run CircuitPython on the Raspberry Pi Pico.
- Interface with the Pico via the interactive REPL (Read-Eval-Print Loop).
- Write structured non-blocking event loops (`while True`) and digital I/O control scripts.
- Bridge software conditionals to physical hardware (lighting LEDs, reading button presses).

## In-Class Activities & Agenda
1. **Flashing the Pico**: Mounting the board as a USB mass storage drive (`CIRCUITPY`) and installing CircuitPython firmware.
2. **REPL Live Session**: Typing interactive Python commands directly into the microcontroller via Thonny / terminal serial console.
3. **Blink & Digital I/O Lab**: Controlling internal and external LEDs with `digitalio`.
4. **Button Input Logic**: Wiring tactile pushbuttons with pull-up/pull-down resistors and debounce handling.
