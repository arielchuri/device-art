1. Operational Overview & Specifications

The HC-SR04 provides non-contact distance measurement using 40 kHz ultrasonic sound bursts. The module emits an 8-cycle sonic burst upon receiving a 10µs trigger pulse, then outputs an Echo pulse whose duration is proportional to round-trip transit time.

2. Pinout & Interconnect Table
PinNameTypePico Connection & Electrical Notes
1VCCPowerConnect to VBUS (5V) or 3V3 (HC-SR04P)
2TrigInputConnect to Pico GP5 (Trigger pulse)
3EchoOutputConnect to Pico GP6 *(See 5V Protection Note)*
4GNDPowerSystem Ground (Connect to Pico GND)
Critical 3.3V Logic Protection (Classic HC-SR04): If powered from 5V (VBUS), the Echo pin outputs a 5V signal. To safely connect to the RP2040's 3.3V-tolerant GPIOs, either use a 1kΩ / 2kΩ voltage divider on the Echo line, or use the 3.3V-native HC-SR04P / RCWL-1601 variant.

4. Enclosure Bezel Design Notes
Dual Barrel Cutouts: Drill two circular holes of Ø 16.5 mm spaced exactly 26.0 mm center-to-center. Bevel or chamfer the front aperture edges to prevent acoustic reflections from triggering false near-field echos.

6. CircuitPython Reading Loop
import time, board
import adafruit_hcsr04

sonar = adafruit_hcsr04.HCSR04(trigger_pin=board.GP5, echo_pin=board.GP6)

while True:
    try:
        dist = sonar.distance
        print(f"Distance: {dist:.1f} cm ({dist / 2.54:.1f} in)")
    except RuntimeError:
        pass  # Sensor timed out or echo missed
    time.sleep(0.05)
