1. Module Overview & Specifications

The 0.96-inch OLED module is a high-contrast graphic display based on the Solomon Systech SSD1306 controller. Operating over a 2-wire I²C bus, each of the 8,192 organic LEDs emits its own light, eliminating the need for a backlight and offering wide viewing angles (>160°) with minimal power consumption.

4. Enclosure Design & Bezel Cutout Recommendations
Enclosure Window Sizing: For laser-cut acrylic or 3D-printed bezels, cut a rectangular viewing aperture of 23.0 mm (W) × 12.0 mm (H). This fully exposes the active matrix while concealing the outer glass borders. Center the cutout 1.5 mm below the PCB mounting hole centerline. Use 4× M2 standoffs (minimum 12 mm height if routing straight header DuPont jumpers).

  • adafruit_display_text/ (Folder for Labels & Text)
6. Minimal CircuitPython Code Example
import board, busio, displayio
from i2cdisplaybus import I2CDisplayBus
import adafruit_displayio_ssd1306
from adafruit_display_text import label
import terminalio

displayio.release_displays()
i2c = busio.I2C(board.GP1, board.GP0)
display_bus = I2CDisplayBus(i2c, device_address=0x3C)
display = adafruit_displayio_ssd1306.SSD1306(display_bus, width=128, height=64)

splash = displayio.Group()
text_area = label.Label(terminalio.FONT, text="Hello Maker!\n0.96 OLED", color=0xFFFFFF, x=8, y=16)
splash.append(text_area)
display.root_group = splash
